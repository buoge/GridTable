# GridTable
GridTable 是表单模板编辑器中的网格布局组件，用于在一个二维表格区域内承载其他表单控件。它本质上不是传统数据表格，而是一个可编辑的布局容器。

grid-table-demo.html 是单页面的 demo 展示

grid-table-vue3 是 vue3 版本的页面展示

grid table.md 是对组件界面的进一步介绍

grid-table-spec.md 是 spec 文档如果大家想自己做一个把文档给 agent 即可复刻
